# CryptoAudit benchmark corpus

Each case lives in `cases/<case_id>/` and is split by information boundary:

| Path | Visible to | Contents |
|---|---|---|
| `public/module.py` | Analyzer, Context Engine, Repair Engine (S1–S4) | The vulnerable program |
| `public/case.yaml` | Repair Engine | Case id, rule id, target Python version, allowed libraries |
| `hidden/oracle.yaml` | Validation only | Which check files back V1/V2/V3, V3 applicability and gating |
| `hidden/v1_functional.py` | Validation only | Functional behaviour checks (V1) |
| `hidden/v2_security.py` | Validation only | Executable cryptographic security-property checks (V2) |
| `hidden/v3_compat.py` | Validation only | Legacy artifact compatibility checks (V3) |
| `hidden/artifacts/` | Validation only | Data persisted by the original implementation |

Rules:

- Repair strategies receive a `PublicCase` (via `BenchmarkRepository.public_case`) and nothing else.
- `cryptoaudit.benchmark.oracle` is the only loader for `hidden/`; an import-boundary test
  prevents repair, context and prompting code from importing it.
- Every hidden file contains a `CANARY: cryptoaudit-hidden-oracle-<case_id>` marker. Leakage tests
  assert no canary ever appears in a repair request or prompt.
- Legacy artifacts are generated by running the original `public/module.py`, so they are exactly
  what the vulnerable implementation persisted.

## Check file format

Check files define `check_*(ctx)` functions. They run inside the validation sandbox through
`cryptoaudit.validation.harness` and use:

- `ctx.load_candidate()` — import a fresh copy of the candidate module
- `ctx.load_json(name)` / `ctx.artifact(name)` — read files from `hidden/artifacts/`

An `AssertionError` is a FAIL; any other exception is an ERROR.

## Adding a case

1. Add `public/module.py` that the CryptoAudit Analyzer flags for the intended rule.
2. Add `public/case.yaml` (no hidden information in it).
3. Add hidden checks and, for V3, artifacts produced by running the original module.
4. Run `pytest tests/integration/test_benchmark_oracles.py`: the original must pass V1 (and V3)
   and fail V2; the reference repair in `tests/fixtures/reference_repairs/` must pass all gates.
